# ATM Cash Withdrawal – Business Analysis Project

## Project Overview
This repository contains a fictional Business Analysis project focused on the ATM cash withdrawal process.
The purpose of this project is to practice Business Analysis techniques by analyzing a business problem, identifying stakeholders, gathering and documenting requirements, analyzing processes, creating user stories and defining acceptance criteria.

## Project Objectives
The objectives of this project are to:
- Understand and define a business problem
- Identify relevant stakeholders
- Analyze the current ATM cash withdrawal process
- Identify problems and improvement opportunities
- Define business and functional requirements
- Create user stories and acceptance criteria
- Develop UAT scenarios

## Project Scope
This is a fictional project created for learning and practicing Business Analysis.
No real bank, customer or confidential information is used.

## Project Structure
The project will be developed step by step and will include:
1. Business Problem
2. Stakeholder Analysis
3. Requirements Analysis
4. Process Analysis
5. User Stories
6. Acceptance Criteria
7. UAT Scenarios

## Learning Approach
This project is designed as a practical learning exercise.

Each stage will be completed through analysis, guided practice and review.

The focus is not only on creating documentation, but on learning how a Business Analyst approaches a business problem.
